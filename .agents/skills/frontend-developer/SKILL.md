# Frontend Developer Skill

Este skill define las responsabilidades, estándares y patrones de desarrollo para el desarrollo Frontend dentro del proyecto.

## 🎯 Enfoque y Responsabilidades

- **Arquitectura de Componentes**: Diseñar componentes en React funcionales, reutilizables y modulares con TypeScript estricto.
- **Sistemas de Diseño & CSS**: Implementar tokens CSS, diseño responsivo, soporte para modo oscuro/claro, animaciones fluidas y estética visual de alto impacto (Glassmorphism, gradients, 3D shadows).
- **Gestión de Estado y API**: Manejar estado local y global, sincronización con APIs RESTful y WebSockets en tiempo real.
- **Rendimiento**: Minimizar re-renders innecesarios, lazy loading, optimización de assets e imágenes.
- **UX & Accesibilidad**: Asegurar navegación fluida, feedback visual inmediato en acciones (spinners, estados disabled, toasts) y atributos aria accesibles.

## 📐 Reglas de Codificación Frontend

1. **TypeScript Estricto**: Definir interfaces o tipos explícitos para props, estado y respuestas API (`client/src/types.ts`).
2. **Sin Placeholders**: Todas las vistas deben contar con datos mock representativos o conexión real a API.
3. **Manejo de Errores Visuales**: Ante fallos de red o validaciones, mostrar banners de alerta amigables sin romper la aplicación.
4. **Diseño Adaptable**: Garantizar que las vistas sean utilizables en resoluciones desktop, tablet y mobile.
