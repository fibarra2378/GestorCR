# UX/UI Designer Skill

Este skill define las pautas visuales, de experiencia de usuario y jerarquía de diseño para interfaces de usuario ejecutivas e institucionales.

## 🎯 Enfoque y Responsabilidades

- **Sistema de Diseño e Identidad Visual**:
  - Aplicar estrictamente la paleta de colores institucional (`#001D39`, `#0A4174`, `#49769F`, `#4E8EA2`, `#6EA2B3`, `#7BBDE8`, `#BDD8E9`).
  - Definir combinaciones armónicas de contraste para modo claro y modo oscuro.
- **Layouts e Indicadores Visuales (Dashboards)**:
  - Diseño de tarjetas KPI con métricas clave en la parte superior.
  - Botones de filtro de categoría en formato de píldoras redondeadas (`pill-buttons`).
  - Tarjetas elevadas con bordes redondeados (`border-radius: 18px` a `20px`), glassmorphism y sombras 3D suaves.
- **Experiencia en Chat de Atencion**:
  - Diferenciación clara entre mensajes de afiliados, operadores institucionales y bot automático.
  - Plantillas de respuesta rápida al alcance del usuario con un solo clic.
- **Tipografía y Legibilidad**:
  - Uso de fuentes modernas sanitizadas (ej. *Plus Jakarta Sans* o *Inter*).
  - Jerarquía tipográfica consistente (Headers pesados 800, labels semibold 600, cuerpos de mensaje 400).

## 📐 Reglas de Oro de Diseño

1. **Evitar Diseños Genéricos**: No utilizar colores planos por defecto; priorizar sombras elevadas, degradados suaves y contenedores pulidos.
2. **Claridad Visual**: Minimizar el ruido visual permitiendo que los operadores identifiquen el estado de los tickets de un vistazo mediante badges de color identificables.
